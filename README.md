# 🚀 TechNova

A modern, responsive React application built with **React Router**, **Tailwind CSS**, and **Vite**. TechNova is a fictional technology company website showcasing routing, reusable layouts, responsive navigation, dynamic routes, and clean UI design.

## 🌐 Live Demo

🔗 **Website:** https://tech-nova-topaz.vercel.app/
---

## ✨ Features

* 🏠 Multi-page application using React Router
* 🎯 Dynamic routing with URL parameters
* 🔗 Active navigation using `NavLink`
* 📱 Fully responsive layout
* 🎨 Modern UI built with Tailwind CSS
* 🧩 Shared layout using `Outlet`
* 🚀 Fast development with Vite
* ❌ Custom 404 Not Found page
* 🦶 Reusable Navbar and Footer components

## 🚦 Routes

| Route          | Description          |
| -------------- | -------------------- |
| `/`            | Home page            |
| `/about`       | About TechNova       |
| `/services`    | Services offered     |
| `/blog`        | Blog page            |
| `/contact`     | Contact page         |
| `/profile/:id` | Dynamic user profile |
| `*`            | Custom 404 page      |

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Ofuluejo/TechNova.git
```

### Navigate into the project

```bash
cd TechNova
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```
